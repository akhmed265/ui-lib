Accordion

Базовый (single)

По умолчанию открыт максимум один раздел. Клик по другому — предыдущий закрывается. Стрелка поворачивается, высота анимируется.

Минималистичная UI-библиотека на чистом HTML, CSS и JavaScript.

Просто подключи ui.css и при необходимости ui.js.

Нет. Только чистые HTML, CSS, JS.

<div class="ui-accordion" data-ui-accordion>
  <div class="ui-accordion__item ui-accordion__item--open">
    <button class="ui-accordion__trigger" type="button">
      <span class="ui-accordion__title">Заголовок</span>
      <span class="ui-accordion__arrow" aria-hidden="true"></span>
    </button>
    <div class="ui-accordion__content">
      <div class="ui-accordion__content-inner">
        Контент
      </div>
    </div>
  </div>
</div>

Multiple

Модификатор --multiple. Можно открыть несколько разделов одновременно.

Можно открыть вместе со вторым.

И не закрывать первый.

Удобно для FAQ.

<div class="ui-accordion ui-accordion--multiple" data-ui-accordion>...</div>

Размеры

Мелкий размер.

Стандартный.

Крупный.

Separated

Каждый раздел — отдельная карточка с зазором.

Отдельная карточка.

С зазором между ними.

Bordered

Акцентная полоса слева у открытого раздела.

С акцентной полосой.

Без полосы.

Disabled

Обычный раздел.

Этот не откроется.

<button class="ui-accordion__trigger" type="button" disabled>...</button>
