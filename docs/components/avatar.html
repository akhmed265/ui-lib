Avatar

Базовый

Картинка или инициалы. С data-name и классом --initials инициалы и цвет генерируются автоматически. 

<span class="ui-avatar ui-avatar--initials" data-name="Иван Петров"></span>

Размеры

Формы

Свой цвет

Переопределяется через --ui-avatar-bg. Авто-цвет не перезапишет заданный вручную. 

<span class="ui-avatar ui-avatar--initials" data-name="Иван Петров"
      style="--ui-avatar-bg: #dc2626;"></span>

Статус

<span class="ui-avatar ui-avatar--status-online">...</span>

Verified

Прогресс-кольцо (опыт до уровня)

Значение от 0 до 100 задаётся через --ui-avatar-progress. Цвет кольца — --ui-avatar-ring-color. 

<span class="ui-avatar ui-avatar--ring"
      style="--ui-avatar-progress: 65;">
  <svg class="ui-avatar__ring" viewBox="0 0 100 100">
    <circle class="ui-avatar__ring-bg" cx="50" cy="50" r="46"/>
    <circle class="ui-avatar__ring-fg" cx="50" cy="50" r="46"/>
  </svg>
  <img class="ui-avatar__img" src="..." alt="">
</span>

Story

Градиентное кольцо как в соцсетях. --story-unread — толще, --story-seen — серое (просмотрено). 

<span class="ui-avatar ui-avatar--story-unread">...</span>
<span class="ui-avatar ui-avatar--story">...</span>
<span class="ui-avatar ui-avatar--story-seen">...</span>

Live

Пульсирующая точка + метка LIVE. --live — только точка, --live-label — точка + подпись под аватаром. 

<span class="ui-avatar ui-avatar--live ui-avatar--live-label" data-name="Стример"></span>
