Чекбоксы

Базовый

Работает без JS. Нативный input визуально скрыт, но доступен с клавиатуры.

<label class="ui-checkbox">
  <input type="checkbox" class="ui-checkbox__input">
  <span class="ui-checkbox__box" aria-hidden="true"></span>
  <span class="ui-checkbox__label">Согласен с условиями</span>
</label>

Размеры

<label class="ui-checkbox ui-checkbox--sm">...</label>
<label class="ui-checkbox">...</label>
<label class="ui-checkbox ui-checkbox--lg">...</label>

Состояния

<input type="checkbox" class="ui-checkbox__input" disabled>
<input type="checkbox" class="ui-checkbox__input" checked disabled>

Indeterminate

Устанавливается через JS: input.indeterminate = true.

document.querySelector("input").indeterminate = true;

Switch

<label class="ui-checkbox ui-checkbox--switch">
  <input type="checkbox" class="ui-checkbox__input">
  <span class="ui-checkbox__box" aria-hidden="true"></span>
  <span class="ui-checkbox__label">Уведомления</span>
</label>
