Поля ввода

Input

Базовое текстовое поле. Обёртка .ui-field — опциональна.

<label class="ui-field">
  <span class="ui-field__label">Email</span>
  <input type="email" class="ui-input" placeholder="you@example.com">
  <span class="ui-field__hint">Мы не передаём email третьим лицам</span>
</label>

<input type="text" class="ui-input" placeholder="Без label — просто инпут">

Размеры

<input class="ui-input ui-input--sm">
<input class="ui-input">
<input class="ui-input ui-input--lg">

Состояния

<input class="ui-input" placeholder="Обычное">
<input class="ui-input" value="Отключено" disabled>
<input class="ui-input" value="Только для чтения" readonly>
<input class="ui-input ui-input--error" value="Некорректное значение">
<input class="ui-input ui-input--success" value="Всё ок">

Field с ошибкой

Модификатор --error на .ui-field и на .ui-input — показывает сообщение об ошибке вместо hint.

<label class="ui-field ui-field--error">
  <span class="ui-field__label">Email</span>
  <input type="email" class="ui-input ui-input--error" aria-invalid="true">
  <span class="ui-field__hint">Мы не передаём email третьим лицам</span>
  <span class="ui-field__error">Введите корректный email</span>
</label>

Textarea

Многострочное поле. Класс .ui-textarea, тянется по вертикали.

<label class="ui-field">
  <span class="ui-field__label">Сообщение</span>
  <textarea class="ui-textarea" rows="4"></textarea>
  <span class="ui-field__hint">Максимум 500 символов</span>
</label>

Input Group

Префикс или суффикс внутри поля — например, для валюты, домена, иконки.

@
.ru
₽ RUB 
<div class="ui-input-group">
  <span class="ui-input-group__prefix">@</span>
  <input type="text" class="ui-input" placeholder="username">
</div>

<div class="ui-input-group">
  <input type="text" class="ui-input" placeholder="example">
  <span class="ui-input-group__suffix">.ru</span>
</div>
