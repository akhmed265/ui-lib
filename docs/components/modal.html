Modal

Базовый

Открывается по data-ui-modal-open="id", закрывается по data-ui-modal-close, клику по overlay или по Esc. 

<button class="ui-btn ui-btn--primary" data-ui-modal-open="my-modal">
  Открыть
</button>

<div class="ui-modal" id="my-modal" hidden>
  <div class="ui-modal__overlay" data-ui-modal-close></div>
  <div class="ui-modal__content" role="dialog" aria-modal="true">
    <header class="ui-modal__header">
      <h2 class="ui-modal__title">Заголовок</h2>
      <button class="ui-modal__close" data-ui-modal-close aria-label="Закрыть">×</button>
    </header>
    <div class="ui-modal__body">Содержимое</div>
    <footer class="ui-modal__footer">
      <button class="ui-btn ui-btn--ghost" data-ui-modal-close>Отмена</button>
      <button class="ui-btn ui-btn--primary">ОК</button>
    </footer>
  </div>
</div>

Размеры

<div class="ui-modal ui-modal--sm" id="..." hidden>...</div>
<div class="ui-modal" id="..." hidden>...</div>
<div class="ui-modal ui-modal--lg" id="..." hidden>...</div>
<div class="ui-modal ui-modal--fullscreen" id="..." hidden>...</div>

Static (важные действия)

Атрибут data-ui-modal-static отключает закрытие по клику на overlay и по Esc. Закрыть можно только явной кнопкой. 

<div class="ui-modal" id="my-modal" hidden data-ui-modal-static>
  ...
</div>

Заголовок модалки

Это базовый пример модального окна. Попробуй закрыть его через крестик, клик по затемнённому фону или клавишу Esc. Tab не выходит за пределы окна — это focus trap.

Small (400px)

Узкая модалка для подтверждений.

Medium (520px)

Размер по умолчанию.

Large (720px)

Широкая модалка для форм и длинного контента.

Fullscreen

Занимает весь экран.

Удалить аккаунт?

Это действие нельзя отменить. Модалка static — клик по фону и Esc не закроют её.
