Progress

Базовый

Значение задаётся через CSS-переменную --ui-progress-value в процентах. 

<div class="ui-progress" style="--ui-progress-value: 60%;">
  <div class="ui-progress__bar" role="progressbar"
       aria-valuenow="60" aria-valuemin="0" aria-valuemax="100"></div>
</div>

С label и значением

Загрузка файла 45% 
<div class="ui-progress" style="--ui-progress-value: 45%;">
  <div class="ui-progress__label">
    <span>Загрузка файла</span>
    <span class="ui-progress__value">45%</span>
  </div>
  <div class="ui-progress__bar" role="progressbar"
       aria-valuenow="45" aria-valuemin="0" aria-valuemax="100"></div>
</div>

Цвета

Размеры

Striped и animated

<div class="ui-progress ui-progress--success ui-progress--striped ui-progress--animated"
     style="--ui-progress-value: 65%;">
  <div class="ui-progress__bar"></div>
</div>

Indeterminate

Когда точный прогресс неизвестен — бегущая полоса.

<div class="ui-progress ui-progress--indeterminate">
  <div class="ui-progress__bar" role="progressbar"></div>
</div>

Loading (пульсация)

Модификатор --loading — заливка мягко пульсирует яркостью. Работает вместе с обычным прогрессом.

Загрузка данных 35% 
<div class="ui-progress ui-progress--primary ui-progress--loading"
     style="--ui-progress-value: 35%;">
  <div class="ui-progress__bar"></div>
</div>

Живой пример

Кнопка запускает загрузку. Во время процесса — пульсация. По завершении — пульсация выключается.

Загрузка 0% 
// Во время загрузки — пульсация
progress.classList.add("ui-progress--loading");

// По завершении — выключаем
progress.classList.remove("ui-progress--loading");
