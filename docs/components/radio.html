Radio

Базовый

Работает без JS. Все радио в группе имеют одинаковый name — это встроенное поведение HTML, только один может быть выбран. 

<div class="ui-radio-group" role="radiogroup" aria-label="Тариф">
  <label class="ui-radio">
    <input type="radio" name="plan" value="free" class="ui-radio__input" checked>
    <span class="ui-radio__box" aria-hidden="true"></span>
    <span class="ui-radio__label">Бесплатный</span>
  </label>

  <label class="ui-radio">
    <input type="radio" name="plan" value="pro" class="ui-radio__input">
    <span class="ui-radio__box" aria-hidden="true"></span>
    <span class="ui-radio__label">Pro</span>
  </label>
</div>

Горизонтально

Модификатор --row у группы.

<div class="ui-radio-group ui-radio-group--row" role="radiogroup" aria-label="Размер">
  ...
</div>

Размеры

<label class="ui-radio ui-radio--sm">...</label>
<label class="ui-radio">...</label>
<label class="ui-radio ui-radio--lg">...</label>

Состояния

<input type="radio" name="st" class="ui-radio__input" disabled>
<input type="radio" name="st" class="ui-radio__input" checked disabled>
