Select

Базовый

Стилизованный нативный <select>. Работает с клавиатурой, формами и мобильным picker из коробки. Своя стрелка через SVG-маску. 

<label class="ui-field">
  <span class="ui-field__label">Страна</span>
  <select class="ui-select">
    <option value="">Выберите страну</option>
    <option value="ru">Россия</option>
    <option value="us">США</option>
  </select>
  <span class="ui-field__hint">Можно изменить позже</span>
</label>

<select class="ui-select">
  <option value="">Без label — просто select</option>
  <option value="1">Опция 1</option>
</select>

Размеры

<select class="ui-select ui-select--sm">...</select>
<select class="ui-select">...</select>
<select class="ui-select ui-select--lg">...</select>

Состояния

<select class="ui-select">...</select>
<select class="ui-select" disabled>...</select>
<select class="ui-select ui-select--error" aria-invalid="true">...</select>
<select class="ui-select ui-select--success">...</select>

Field с ошибкой

Как у input: --error на .ui-field скрывает hint, показывает error, а --error на .ui-select красит рамку. 

<label class="ui-field ui-field--error">
  <span class="ui-field__label">Город</span>
  <select class="ui-select ui-select--error" aria-invalid="true">
    <option value="">Выберите город</option>
    <option value="msk">Москва</option>
  </select>
  <span class="ui-field__hint">Обязательное поле</span>
  <span class="ui-field__error">Пожалуйста, выберите город</span>
</label>
