</span>

В кнопке

Спиннер хорошо встраивается в flex-кнопку. 

<button class="ui-btn ui-btn--primary" disabled>
  <span class="ui-spinner ui-spinner--sm"></span>
  Сохранение...
</button>

<button class="ui-btn ui-btn--secondary" disabled>
  <span class="ui-spinner ui-spinner--dots ui-spinner--sm ui-spinner--primary">
    <i></i><i></i><i></i>
  </span>
  Загрузка
</button>

Overlay

.ui-spinner-overlay — спиннер поверх блока. Родитель должен иметь position: relative.
