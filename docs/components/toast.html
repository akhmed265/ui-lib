Toast

Базовый

Тост вызывается через UIToast.show({...}) или через data-ui-toast на любом элементе. По умолчанию — top-right, 4000 мс, кнопка закрытия. 

<button data-ui-toast="Это базовое уведомление">Показать</button>

// или через API
UIToast.show({ message: "Это базовое уведомление" });

Типы

UIToast.show({
  type: "success",
  title: "Сохранено",
  message: "Изменения применены",
});

Позиции

data-ui-toast-position: top-right (по умолчанию), top-left, top-center, bottom-right, bottom-left, bottom-center. 

<button data-ui-toast="Top left" data-ui-toast-position="top-left">...</button>

Длительность

data-ui-toast-duration в миллисекундах. 0 — не закрывать автоматически. 

<button data-ui-toast="..." data-ui-toast-duration="1000">1 сек</button>
<button data-ui-toast="..." data-ui-toast-duration="0">Не закрывать</button>

Пауза на hover

Наведи курсор на тост — таймер замрётся. Убери — обратный отсчёт продолжится.

Лимит и API

Одновременно на экране — не больше 5 тостов. Старые вытесняются новыми. Можно закрыть все программно через UIToast.closeAll(). 

UIToast.show({ message: "..." });
UIToast.closeAll();
