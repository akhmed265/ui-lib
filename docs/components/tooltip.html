Tooltip

Базовый

Любой элемент с data-ui-tooltip="текст". Показывается по hover, по focus (Tab), скрывается по Esc и по клику. Задержка по умолчанию — 200 мс. 

<button class="ui-btn ui-btn--primary" data-ui-tooltip="Это подсказка сверху">
  Наведи на меня
</button>

Позиции

data-ui-tooltip-placement: top (по умолчанию), bottom, left, right. Если не влезает — автоматически переворачивается. 

<button data-ui-tooltip="Сверху" data-ui-tooltip-placement="top">Top</button>
<button data-ui-tooltip="Снизу" data-ui-tooltip-placement="bottom">Bottom</button>
<button data-ui-tooltip="Слева" data-ui-tooltip-placement="left">Left</button>
<button data-ui-tooltip="Справа" data-ui-tooltip-placement="right">Right</button>

Задержка

data-ui-tooltip-delay="0" — показ мгновенно. Можно задать любую задержку в миллисекундах. 

<button data-ui-tooltip="Показ мгновенно" data-ui-tooltip-delay="0">Delay: 0</button>
<button data-ui-tooltip="Через 1 секунду" data-ui-tooltip-delay="1000">Delay: 1000</button>
