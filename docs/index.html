UI Lib

UI Lib

Минималистичная UI-библиотека на чистом HTML, CSS и JavaScript. Выбери компонент, чтобы посмотреть примеры и код.

Кнопки

Primary, secondary, ghost, danger, link. Размеры и состояния.

Чекбоксы

Скошенный угол, анимированная галочка, switch, indeterminate.

Radio

Радиокнопки с градиентом и свечением. Группы, размеры, состояния.

Поля ввода

Input, textarea, размеры, состояния, input-group с префиксом и суффиксом.

Select

Стилизованный нативный select: размеры, состояния, плейсхолдер, своя стрелка.

Modal

Модальные окна с overlay, анимацией, focus trap и режимом static.

Tooltip

Всплывающие подсказки на hover и focus. 4 позиции, авто-флип, задержка.

Toast

Всплывающие уведомления. 4 типа, 6 позиций, стек, пауза на hover.

Card

Контейнеры для контента. Части, размеры, accent, horizontal, hoverable.

Tabs

Переключатель панелей. Underline и pills, размеры, клавиатура, ARIA, scrollable.

Accordion

Сворачиваемые секции. Single и multiple, размеры, separated, bordered.
